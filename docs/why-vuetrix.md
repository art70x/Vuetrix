# Why Vuetrix

Vitesse is the reference Vue starter, and its README says it is now maintained slowly. Vuetrix keeps its structure and updates the stack.

| | Vitesse | Vuetrix |
|---|---|---|
| Styling | UnoCSS | Tailwind 4 + shadcn-vue |
| Linting / formatting | ESLint with @antfu/eslint-config | Oxlint + Oxfmt, ESLint for Vue-specific rules |
| Static builds | vite-ssg | vite-ssg + sitemap + robots.txt |
| State, i18n, PWA | Included | Not included. Add what you need. |

Choose Vuetrix if you want shadcn-vue components and the Oxc toolchain on day one. Choose Vitesse if you want i18n, PWA, and Markdown pages out of the box.
